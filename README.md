# Library Recommendation Slide Tool

Simple Hebrew RTL slide editor for library staff.

## Run locally

Open `index.html` directly in your browser, or run a static server.

## Deploy to Vercel

1. Push this repo to GitHub/GitLab/Bitbucket.
2. In Vercel, click **Add New Project** and import the repository.
3. Keep framework preset as **Other** (or Static).
4. Deploy.

### Why this works

- `index.html` is a static single-file app.
- `vercel.json` rewrites all paths to `index.html`, so direct links still work.
- No backend or build step required.
